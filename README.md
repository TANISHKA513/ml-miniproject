# SmartSpam – SMS Spam Classification using Machine Learning

SmartSpam is a machine learning project that automatically classifies SMS messages as **Spam or Ham (Legitimate)** using Natural Language Processing (NLP). The project uses the **UCI SMS Spam Collection** dataset, applies text preprocessing and **TF-IDF** feature extraction, and compares multiple ML algorithms including **Naive Bayes, Logistic Regression, SVM, and Random Forest** to identify spam messages.

## Tech Stack

* Python
* Pandas & NumPy
* Scikit-learn
* NLP & TF-IDF
* Machine Learning
